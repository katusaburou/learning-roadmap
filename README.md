# IoT機器向けの組込み・サーバー学習

IoT機器のデータが、機器本体から中継プログラムを経由してサーバーに届き、保存・表示されるまでを学ぶための公開ロードマップです。C言語と組込みの基礎を中心に、電子回路、通信、Linux、Node.js、MQTTを小さな実習で結び付けます。

週10時間、20週間（約200時間）を目安に進めます。開始日は固定せず、自分の進捗と利用できる環境に合わせて調整します。このリポジトリには計画・週報・成果の説明を置き、実装や実験は別の作業環境で行います。

## 学習の流れ

```text
Cの模擬機器 → シリアル通信 → Node.jsの中継 → MQTT → 保存 → 簡単な表示
```

最初はファイルや標準入出力の模擬データで接続し、仮想シリアルや実機を利用できる段階で置き換えます。
