# 週報

毎週日曜日を目安に、[テンプレート](../templates/weekly-report.md)から `YYYY-Www.md` を作成します。ファイル名の週番号はISO週番号（月曜始まり）を使い、本文には開始日・終了日と、[学習計画](../plan.md)の何週目に当たるかを記載します。休んだ週や遅れを調整した週があるため、ISO週番号と計画上の週は一致しなくても構いません。

週報を追加したら、この一覧と[README](../README.md)の最新週報リンクを更新します。実施していない作業は予定として書き、学習時間は実績を記録します。

## 一覧

まだ週報はありません。追加したら、新しい順に `- [YYYY-Www](YYYY-Www.md)：計画第○週・主な内容` の形で並べます。
